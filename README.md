# 🌐 Flask Web Project

Учебный проект по созданию веб-приложения на Python с использованием фреймворка Flask.

## ✨ Возможности
- 🏠 Главная страница (`/`)
- ℹ️ Страница "О проекте" (`/about`)
- 📝 Лог изменений (`/changelog`)
- 🎨 Современный адаптивный дизайн (CSS)

## 🛠 Технологии
- **Python 3**
- **Flask** (микрофреймворк)
- **Jinja2** (шаблонизатор)
- **HTML5 / CSS3**
