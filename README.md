## 🛠️ Как это запустить? (Для тех, кто хочет повторить мой успех)

1. Установи Flask: 
   `pip install flask`
2. Запусти мой шедевр:
   `python app.py`
3. Открой браузер и перейди по ссылке: `http://127.0.0.1:5000` 🌐
4. Наслаждайся моей красотой ✨😌
