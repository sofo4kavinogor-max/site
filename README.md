# Менеджер задач (Task Manager)

## Назначение

Веб-приложение для управления задачами и проектами. Позволяет создавать задачи,
отслеживать их статус, приоритет и сроки, а также управлять проектами.

## Функциональность

- CRUD-операции для задач и проектов
- Канбан-доска (todo / in_progress / done)
- Статистика по задачам
- История изменений задачи (создание, смена статуса)
- Разграничение доступа: пользователь видит только свои задачи
- Бизнес-правила: запрет недопустимых переходов статуса
- Серверная фильтрация: `?search=`, `?status=`, `?project=`, `?ordering=`

## Технологии

- Python 3.13
- Django 6.1
- Django REST Framework
- SQLite (локально)
- Tabler UI Kit
- JavaScript (fetch API)
