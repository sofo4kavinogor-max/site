# 💻 Мой Flask-проект 🌸

Привет! Это мой небольшой учебный проект по веб-разработке на Python и Flask. 💖

Я постаралась сделать его не только функциональным, но и приятным глазу ✨

### 📌 Что внутри:
* 🏠 **Главная** — краткое знакомство с проектом.
* 📝 **Тест** — небольшой опрос, где можно проверить себя.
* 💌 **О проекте** — информация о сайте и форма для отзывов.
* 📜 **Лог изменений** — история того, как развивался проект.

### 🚀 Как запустить:
1. Установи Flask:
   `pip install flask`
2. Запусти приложение:
   `python app.py`
3. Открой в браузере:
   `http://127.0.0.1:5000`
