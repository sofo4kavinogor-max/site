# LOOKSMAXING

Учебный веб-проект на Flask.

## О проекте

Небольшой сайт о фитнесе и питании. Сделан в рамках практической работы.

## Что есть

- Главная страница
- Калькулятор калорий и БЖУ
- Тёмная и светлая тема

## Стек

Python, Flask, HTML, CSS, JavaScript

## Запуск

pip install flask requests
python app.py

Открыть в браузере: http://127.0.0.1:5000/
