# Пикми-сайт 💜

Привет! Это мой учебный проект на Flask — многостраничный сайт с тестами, нумерологией и котиками 🐱

### Что внутри:
- Главная, О проекте, Лог изменений, Увлечения
- Тест с результатами и котиками
- Нумерология совместимости на звёздном небе ✨
- Галерея котиков

### Запуск:
1. `pip install flask`
2. `python app.py`
3. Открой `http://127.0.0.1:5000`

Сделано с любовью к коду 💕
